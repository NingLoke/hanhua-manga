==========================================================
            一键汉化漫画 4.0.5  使用说明
==========================================================

【一、选哪个版本？】
  ● 通用显卡版（推荐）：有独立显卡或较新的核显（NVIDIA / AMD / Intel 都可以），
    Windows 10 1903 以上。速度快、安装包小。
  ● NVIDIA 加速版：NVIDIA 显卡（GTX 10 系及以上，驱动 580 以上），追求最快速度时选它。
    安装包较大（含 CUDA 运行库）。
  ● CPU 轻量版：没有独立显卡、老电脑、或显卡版打不开时用它。速度较慢但最省资源。
  打开软件后，「关于」页会显示本机硬件，并提示最适合的版本。

【二、开始汉化】
  1. 解压后双击「一键汉化漫画.exe」。
  2. 把漫画拖进窗口（可以一次拖多本），或点「添加文件」「添加文件夹」。
     也可以直接把漫画拖到 exe 图标上打开。
  3. 软件会自动：识别气泡和文字 → 识别原文 → 翻译 → 擦除原文并修复背景 → 嵌入中文 → 输出图片文件夹。
  4. 完成后点「打开」，默认保存在原漫画旁边，名称带「_汉化_竖排左到右」等排版后缀。
     每次拖入都建立独立任务，同一漫画可分别制作左右、右左两版，重复版本自动加序号，不覆盖旧成品。
     在「设置 → 语言与阅读方向」选择从左到右 / 从右到左；这一项直接控制竖排列顺序。

【三、支持的格式】
  输入：文件夹、单张或多张图片（jpg / png / webp / bmp / tif / gif / avif）、
        zip / cbz、7z / cb7、rar / cbr、tar / cbt、pdf、epub，以及「压缩包里套压缩包」的合集。
  输出：图片文件夹（默认），或 cbz / zip / pdf / epub；图片可选 jpg / png / webp。
  源语言：日文漫画（竖排 / 横排）、韩漫长条、英文漫画。目标：简体中文或繁体中文。

【四、中途断了怎么办？】
  不用担心。每一页的每一步都会自动保存。关掉软件、断电、断网都没关系，
  再次打开软件会恢复队列里的任务；点任务上的「继续」接着处理，已完成的页面不会重做。
  重新拖入漫画会建立新任务，从头处理，不按书名或旧记录跳过。
  删除任务会清理该任务的处理进度；原漫画和已导出成品保留。
  翻译服务暂时连不上时，任务会自动暂停并定时重试，联网后点「继续」即可。

【五、不满意某一页？用「校对」】
  在任务卡片上点「校对」：
  ● 点选任意文字块，直接修改原文或译文，点「应用并重排」立即生效（不用重跑整本）。
  ● 可以单独设置字体、字号、横排 / 竖排、颜色、描边，或勾选「保留原文」。
  ● 按住空格键临时查看原图；← → 翻页；Ctrl+S 保存。
  ● 改完点「重新导出」生成新的成品。

【六、常用设置】
  ● 画质档位（顶栏）：极速 / 均衡 / 高质量。低配电脑选「极速」。
  ● 翻译（默认本地翻译，离线、不限次数）：
    ① 本地大模型（首选）：软件会自动识别你的显卡 / 显存 / 内存，推荐最适合的本地翻译模型
      （例如 16GB 显存推荐 Qwen3.5 9B，8GB 推荐 4B，没有独显用 CPU 跑小模型）。
      第一次使用在「设置 → 翻译」点「下载」即可（国内自动走镜像，支持断点续传），也可以「导入模型」用自己的 .gguf。
      整页一起翻译、带上下文和术语表，人名前后一致、语气自然。顶栏选「极速」会自动换更快的小模型。
    ② API 服务（其次）：填入 DeepSeek / 硅基流动 / OpenAI / Gemini / OpenRouter 等的 Key 即可使用。
    ③ 免费在线翻译（兜底）：本地模型还没下载、也没填 Key 时自动使用，可在设置里关闭。
  ● 术语表：人名、专有名词固定译法（如 マネージャー → 经理）。
  ● 拟声词：翻译替换 / 保留原样 / 只擦除。
  ● 排版：对白、旁白、拟声词分别选字体；横排 / 竖排；字号范围；描边粗细。

【七、常见问题】
  Q：打不开 / 闪退？
  A：先试「CPU 轻量版」。若提示缺少 WebView2，请安装微软 Edge WebView2 运行时
     （Windows 10/11 一般已自带）。日志在 %APPDATA%\HanhuaManga\logs\app.log。
  Q：显卡版提示已切换到 CPU？
  A：显卡驱动太旧或显存不足，请更新显卡驱动；软件会自动降级继续工作，不会中断。
  Q：翻译提示「暂时不可用」？
  A：用的是免费在线翻译时偶尔会被限流，软件会自动暂停并定时重试。建议在「设置 → 翻译」下载本地模型，
     离线翻译不受网络影响。
  Q：本地翻译模型启动失败 / 提示显存不足？
  A：在「设置 → 翻译」换一个更小的模型（如 4B），或把画质档位调成「极速」。
